<h2> Card Validation API </h2>

<p1> Card Validaton API- is a single POST endpoint used to test a cardNumber validity. </p1>
<br>
<p2> The endpoint validate different card types such as ; Master, Visa, Discover, JCB & American Express </p2>

<h2> To run </h2>

<p3> npm install </p3>
<br>
<p4> npm run dev </p4>
